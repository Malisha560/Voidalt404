# Exora (Smart Admit Card)

## Overview
Exora is an examination entry management system that replaces physical admit cards with a fee-gated, dynamic QR verification process. 

## Key Features
- **Fee-Gated Dashboard:** Exam schedules are restricted to students with cleared tuition dues.
- **Dynamic QR Admit Cards:** QR codes (containing block and seat details) are generated 2-4 hours before the exam to prevent proxy attendance and early misuse.
- **Invigilator Portal:** A scanning interface for real-time attendance logging, including accept/reject workflows and manual lookups for students without mobile devices.
- **Administrative Efficiency:** Removes the need for physical printing, distribution, and reprinting of lost admit cards.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js (REST API)
- **Database:** MySQL
- **Security:** JWT embedded in QR codes

## Out of Scope
- Real-time payment gateway integration.
- Automated SMS notifications.
- Multi-campus seating optimization.
